# 拼布画视觉风格系统

## 核心命题

**主体由布片构成（subject-as-fabric）。**

画面必须让人相信：主体是被剪出来、拼起来、缝在底布上的，而不是先画一张插画、再盖一层布纹滤镜。判断是否达标，用三个问题：

1. 遮住布料纹理后，主体轮廓是否仍由布片边缘构成？
2. 主体内部是否能看出不同布片的接缝、叠压或拼块？
3. 边缘是否有可见的布纤维、缝线或固定方式？

三个问题有一个答“否”，就等于失败，需要重做主体构造，而不是加纹理。

## 风格定位

温暖、家常、故事书式的现代手作拼布。像祖母留下的手作，但构图干净、有编辑设计感；不是复古做旧，也不是高级时装布艺。

默认四种工艺模式，允许混合，但一幅作品最多混用两种：

1. **贴布 Appliqué（照片转拼布默认）**：一个可辨认主体，用 6–15 块宽大的布片剪影拼成，边缘以缝线固定。
2. **布片拼贴 Fabric collage**：主体内部由 10–24 块不同图案的碎布拼成，毛边明显，拼块感强。
3. **几何拼布 Geometric patchwork**：用方块、三角、六边形等规则单元拼出母题，16–60 个单元。
4. **毛毡贴布 Felt appliqué**：纯色毛毡剪出干净边缘，少量缝线，适合儿童、卡通、简约需求。

## 构图

- 默认画幅 `3:4` 竖版；可接受 `1:1`、`4:5`，以用户指定为准。
- 主体外接框约占画幅宽度 50–72%、高度 45–65%；主体与所有文字离画布边缘至少 8%。
- 单一主体时保持 25–40% 安静底布；叙事型散点构图至少 30% 留白，不能把画面填满。
- 提供三种可复用版式：
  - **居中主角**：一个主体居中或略偏下，背景纯净，适合照片转单主体。
  - **叙事散点**：一个大锚点 + 3–6 个小物件环绕，适合场景、餐桌、花园等主题。
  - **边框画框**：底布外围 3–8% 宽度的布条包边或图案布边框，内部是一整幅画面。
- 物件之间允许小错位和轻微不平行，但整体重心必须稳定；不要出现漂浮、悬空、贴纸感排列。
- 不要把挂杆、桌面、手、切割垫、墙面等拍摄环境画进成品，除非用户明确要求。

## 模式 A 的成品画布

照片转拼布时，默认输出一张“照片 + 拼布”的浅黄布面画纸：

- **整张画纸是浅暖黄色布面**（默认 `#F4E6C4`），四边有棕色细线和棕色缝线。
- 原照片放在上方，占画布面积约 60–65%，是画面里更大的元素；照片像素、裁切、光影和颜色全部保留。
- 拼布放在下方独立区域，占画布约 20–25%；两个区域之间留 3–6% 的间隙，**绝不重叠**。
- 照片边缘外侧加棕色针脚，针脚不能画进照片像素；拼布直接落在浅黄布面上，不加卡片或第二层背景。
- 拼布保持严格平面：无填充、无鼓包、无投影。

## 配色

从参考图提取出的核心色板，按角色使用：

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 奶油白 | `#F6F1E4` / `#EFE6D6` | 主底布、留白、浅色布片 |
| 亚麻米 | `#E4D9C3` / `#D9C9A8` | 底布、麻布、次级布片 |
| 砖红 | `#9E3B2E` | 主强调色、毛毡、轮廓缝线 |
| 灰粉 | `#C7A9A6` / `#D9B9B5` | 柔和主体、女性化主题 |
| 芥末黄 | `#DDBB74` | 暖色点缀、食物、花朵 |
| 鼠尾草绿 | `#8D9B77` | 植物、叶片、平衡色 |
| 深橄榄 | `#4C5A46` | 深色布片、深色图案 |
| 雾蓝 / 牛仔蓝 | `#6E8391` / `#33475A` | 冷色主体、天空、餐具 |
| 可可棕 | `#6E4A3C` | 麻布、木质、深色图案 |
| 炭黑 | `#2C2A28` | 缝线、瞳孔、极少量深色 |

规则：

- 每幅作品使用 2–4 个彩色 + 1–2 个中性色，彩色总数不超过 5，强调色最多 1 个。
- 饱和度控制在 25–55%，避免荧光色、纯正红黄蓝。
- 图案布可以承担“颜色”的角色：格纹、波点、碎花本身就是色块。
- 允许 1–2 处小面积高对比（如红色果酱配奶油布），但不要通篇高对比。
- 布片叠合处允许轻微透色、加深，模拟两层布的相互影响。

## 布料材质库

优先使用有真实织物质感的棉麻类布料：

| 布料 | 特征 | 适用 |
| --- | --- | --- |
| 平纹棉布 | 细腻、哑光、可见经纬 | 大面积底布、主体 |
| 印花棉布 | 小碎花、草莓、波点、小图案 | 主体内部拼块 |
| 格纹布 | 红白格、棕格、彩色格 | 视觉焦点、边框、叶片 |
| 条纹 / 铅笔条 | 细条纹、牛仔条 | 背景、服装、器物 |
| 亚麻 | 粗纤维、自然色差、轻微褶皱 | 底布、自然主题 |
| 麻布 / 粗麻 | 明显粗纱、棕色 | 地面、篮筐、乡村感 |
| 毛毡 | 无经纬、绒面、边缘干净 | 卡通、儿童、食物、简化造型 |
| 蕾丝 / 缎带 / 包边条 | 半透、细密、装饰性 | 点缀，面积 ≤10% |

规则：

- 每幅作品至少混用 2 种布料或 2 种图案，不能整幅只用一种纯色布。
- 图案重复尺寸约为所在布片短边的 2–8%；碎花要明显小于布片，不能一朵花占满整块布。
- 布料必须哑光或有极弱的棉质光泽；禁止塑料感、丝绸高光、金属反光。
- 印花不能是照片贴图，也不能是高精度写实花卉；应是有限套色、边缘略柔和的印染效果。

## 布片形状与构造

- **主体剪影**：宽大、连贯、可辨认，靠 1–3 个识别锚点成立（猫耳与尾巴、茶壶嘴与把手、草莓的叶冠）。
- **内部拼块**：布片拼贴模式用 10–24 块；贴布模式用 6–15 块；几何模式 16–60 个单元。
- 优先大块面，碎小色块总面积不超过主体的 30%；不要做成马赛克或纸屑拼贴。
- 几何拼布只允许 3–5 种图案布，靠排列和比例产生变化，而不是无限换布。
- 贴布轮廓可以有 2–4 级简化：先保留外轮廓，再用 1–2 块深色布表达转折，不追求写实光影。
- 允许不对称、手工裁剪的轻微歪斜；禁止完美矢量对称。

## 布片边缘

边缘是拼布感成立的关键，必须能看出“这块布是怎么被处理的”：

- **毛边 raw fray**：边缘露出 1–3 mm 等效宽度的白色/本色纤维，呈不规则断续，不是均匀锯齿。只让 30–70% 的布片出现明显毛边，其余保持较干净的剪边。
- **干净剪边 clean cut**：毛毡和部分棉布可以是利落剪边，但仍应有极细的织物毛茸，不能像矢量硬边。
- **包边 / 折边**：主体外轮廓或画框边缘可用 2–4% 画幅宽度的布条包边，缝线可见。
- **锁边 / zigzag**：用于固定方片或重毛边布片，线迹宽 2–4 px 等效，颜色可比布片深或浅一档。
- 边缘允许轻微卷曲、起毛、线头，但必须克制；单幅作品中花哨边缘不超过三处。
- 禁止统一的白边描边、白色描边光晕、电脑生成的规则锯齿。

## 叠层与平面性

- **严格平面贴布**：布片平铺并缝在底布上，只有 1–2 层叠压；不做填充、不起翘、不做倒角、不做对象级投影。
- 层与层之间只用 1–2 px、≤12% 不透明度的极细接缝暗线分隔，让人看出接缝，而不产生“浮起”的立体感。
- 不画布料厚度高光、边缘倒角、体积明暗；布片应像被熨平后缝住，而不是纸雕或软包。
- 叠压顺序必须清楚：后层完整、前层压边、缝线穿过前层固定到后层。
- v1 统一采用平面拼接，不提供立体软雕；任何填充、鼓包、起翘都属于失败，需重做。

## 针脚与手工痕迹

针脚不是装饰，而是“这块布被缝住了”的证据：

- 常用针法：平针 running stitch、回针 backstitch、毯边缝 blanket stitch、zigzag、十字绣 cross stitch、法式结 French knot。
- 主体外轮廓的 40–80% 应有可见缝线；不必每块布都缝满。
- 缝线宽 1–3 px 等效，针距 8–16 px；毯边缝间距 10–18 px，允许 ±20% 不均匀。
- 每幅作品使用 1–3 种线色，优先米白、砖红、深棕、炭黑；避免彩虹色线。
- 允许线头、起针结、轻微歪斜、断线；禁止完美等距、机器矢量线。
- 可以用线迹补充细节（鱼鳞、叶脉、胡须、文字），但线迹不能替代布片主体。

## 底布与背景

- 底布必须是一整块有织物纹理的布：奶油棉布、亚麻、格纹、细条纹或波点布。
- 底色保持低对比，不能抢主体；纹理可见但不脏。
- 可选 3–8% 宽的图案布边框、包边条或荷叶边，但只选一种，不要层层叠加。
- 背景不画天空渐变、光斑、纸张纹理、复古做旧、墙纸花纹；这些会破坏“实物拼布”的可信度。

## 光影

- 柔和窗光，方向以左上或环境漫射为主；整体偏亮、低对比。
- 不画布片投影；只用极细接缝暗线区分上下层。
- 允许织物自身的极轻微明暗变化，但不得形成体积、鼓包或倒角。

## 文字

- 默认无文字。
- 用户要求文字时，最多 1 行短标题（建议 ≤3 个英文词或 ≤8 个汉字），面积不超过画幅宽度的 20%。
- 可选手写绣线字、盖章感手写体或打字机字体；颜色取深可可或炭黑。
- 文字必须准确、可读、位置安全；禁止无意义小字、仿品牌字样、水印。

## 质量检查清单

交付前逐条确认，任意一条失败即需修正：

1. 主体轮廓是否由布片构成，而不是画好后盖纹理？
2. 是否至少混用 2 种布料或图案？
3. 是否至少有一处可见毛边或缝线固定？
4. 彩色是否 ≤5 种，强调色 ≤1 种？
5. 主体外接框、文字、装饰是否都在 8% 安全边距内？
6. 留白是否 ≥25%，画面没有填满？
7. 碎小色块是否 ≤30% 主体面积？
8. 是否严格平面：叠层 ≤2 层，无填充、起翘、倒角、投影或体积高光？
9. 是否没有渐变、塑料高光、矢量硬边、写实照片贴图？
10. 是否没有房间、手、工具、挂杆等未要求的拍摄环境？
11. 文字是否准确且不过量？
12. 整体是否温暖、干净、像真实手作，而不是复古做旧或儿童手工课作品？
13. 模式 A 是否为浅黄布面、四周棕色线、照片与拼布不重叠，且照片外沿有针脚？

## 排除项

除非用户明确要求，否则不要出现：

- 数字渐变、光滑矢量填充、3D 渲染高光、塑料或金属质感
- 直接贴真实布料照片、写实印花照片、照片裁片
- 胶带、纸张拼贴、手账胶带质感（不要漂移到别的工艺）
- 密集马赛克、纸屑式碎块、彩虹配色
- 3D 填充、鼓包、起翘、倒角、对象投影、毛绒玩具感、立体纸雕感
- 挂杆、衣架、墙面、桌面、手、剪刀、切割垫、缝纫机等环境元素
- 复古做旧、污渍、烧焦边、浓重颗粒、电影感打光
- 品牌字样、无意义英文小字、印章、水印、签名
- 完美机器缝线、等距针脚、统一白边
- 照片与拼布重叠、拼布盖住照片、照片没有边缘针脚

## 维护方法

这份文件不是一次写成的，按下面的循环迭代：

1. 选一张新参考图，用下面的拆解表逐项填写。
2. 多张图横向对比，提取共性。
3. 把共性写成“做什么 + 数字区间 + 禁止什么”的规则。
4. 生成 5–10 张测试图，记录失败类型。
5. 把新失败追加到排除项或质量检查清单，回到第 1 步。

拆解表模板：

| 维度 | 记录内容 |
| --- | --- |
| 构图 | 主体占比、位置、留白、边距、版式 |
| 配色 | 主色数量、明度、饱和度、强调色、叠色 |
| 光影 | 光源方向、阴影软硬、整体明暗 |
| 布片形状 | 几何 / 有机、大小比例、碎块程度 |
| 抽象度 | 识别锚点、简化级别 |
| 叠层 | 层数、接缝线、是否填充（默认必须为否） |
| 材料 | 布种、织法、图案、光泽 |
| 边缘 | 毛边 / 剪边 / 包边 / 锁边、出现频率 |
| 手工痕迹 | 针法、线色、针距、线头、褶皱 |
| 排除项 | 这张图里幸好没有出现的东西 |

## AI 与 Python 的分工

- **AI 负责**：理解照片主体、决定抽象程度和布片分区、选择布料与配色、生成拼布主体图像。
- **Python 负责**：画布尺寸与比例、安全边距、透明背景合成、布纹叠加、毛边与缝线细节、接触阴影、文字排版、最终质检参数输出。

原则：构图、边距、文字、毛边这类可以精确计算的事交给脚本；只有“这块布该怎么拼”这种审美判断交给生成模型。

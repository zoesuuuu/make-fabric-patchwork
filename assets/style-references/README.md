## 使用原则

- 默认只读取上面 5 张“主要参考”。
- 风格参考图永远不提供具体主体；主题必须来自用户照片或文字需求。
- 参考图中的墙面、手、切割垫、挂杆、衣领等环境元素默认不进入成品。
